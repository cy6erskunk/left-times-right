# left-times-right

Your primary school multiplication trainer with emojis

## Development

Tooling is provided by [Vite+](https://viteplus.dev) (`vp`), configured in `vite.config.ts`:

- `npm run dev` – start the dev server
- `npm run check` – format check, lint and type check (`npm run check-fix` to autofix)
- `npm test` – run the tests
- `npm run build` – production build into `build/`
